## 1단계 · 시작

사이트를 열면 **"어떻게 만들까요?"** 팝업이 뜹니다.

- **예약 정보 붙여넣기**: 예약 시스템의 「상품 정보」를 그대로 붙여넣고 **자동 채우기**.
  - 형식이 맞지 않으면 팝업 안에 오류가 뜨고 팝업이 남습니다.
  - 확인할 점(목록에 없는 상품, 견적 합계와 예약 금액 차이 등)이 있으면 화면 맨 위 **"예약 정보 확인"**에 나오고 품목 칸이 펼쳐집니다.
- **직접 생성하기**: 빈 문서에서 시작합니다. 품목 칸이 **문서 생성하기**로 펼쳐집니다.

**새로 작성**(출력 칸) 또는 단계 표시의 ①을 누르면 지금 내용을 지우고 시작 팝업이 다시 뜹니다(작성 중이면 지울지 먼저 물어봄). 팝업에서 아무것도 고르지 않고 닫으면 작성하던 내용이 그대로 남습니다.

### 기본 정보

|---|---|

| 결제 | **인터넷 결제**: 모든 품목을 ㈜사유원 견적서 한 장으로 (관람만 있으면 면세, 과세 품목이 섞이면 VAT 포함)<br>**현장 결제**: 관람은 ㈜사유원(면세), 식음 · 프로그램 · 대관은 신라철강㈜(VAT 포함)으로 나눔<br>*결제 방식이 정해지지 않았으면 인터넷 결제* |

### 내부용 문서 편집 · 문서 생성하기 (품목)

예약에서 채웠으면 **내부용 문서 편집**, 직접 생성했으면 **문서 생성하기** 버튼으로 품목 칸을 엽니다(기능은 같음).

- **내부용 품목 순서**: 품목 칸 맨 위 목록에서 ⋮⋮를 잡고 끌어 놓거나 ▲▼로 순서를 바꿉니다(양식별). 끄는 중 커서가 화면 위 · 아래 끝(또는 화면 밖)으로 가면 저절로 스크롤됩니다. 내부용 문서와 아래 품목 카드 순서가 같이 바뀌고, 외부용은 따로 순서를 정하지 않았으면 이 순서를 따릅니다. 할인 줄은 늘 맨 아래입니다.

- 줄마다 **품목**(목록에서 고르면 단가 · 할인 대상이 자동) · **품명**(문서에 찍히는 이름) · **수량** · **정상 단가** · **할인율 %** · **비고**(할인율에 맞춰 자동)를 고칠 수 있습니다.
- 품목마다 수량이 다르면(입장 18명, 모과청 15개 등) 여기서 수량을 직접 고칩니다.
- 아래 **+ 관람** / **+ 식음·프로그램**으로 줄을 더하고, 줄 오른쪽 ✕로 지웁니다.
- **할인 줄**(예약의 기타할인, 단가를 마이너스로 넣은 줄)은 비고 칸이 **「내부용 비고 (외부용에는 안 나옴)」**으로 바뀝니다. 여기 적은 글씨는 내부용 문서에만 찍히고, 외부용에서는 할인 한 줄로 합쳐져 비고 없이 나옵니다.
- 하단 안내문구(선택): 쓰면 견적서 아래에 인쇄됩니다.
- 여기서 고친 내용이 **모든 문서의 기준**입니다. 외부용도 바로 따라 바뀝니다.

### 자동 채우기 규칙

- 예약 상품명이 [품목 관리](#품목-관리) 목록과 같으면 그 품목으로 들어갑니다. 목록에 없으면 "예약 정보 확인"에 알려 줍니다.
- **관람+식사 패키지**(예: 평일(관람, 사담 런치1부))는 관람(㈜사유원)과 식사(신라철강㈜) 두 줄로 나눕니다. 식사 단가 = 정상가 − 관람료.
- **할인율**: 예약에 적힌 %를 할인 대상 품목(관람, 사담 다이닝 등 「할인 대상」에 체크된 품목)에만 적용합니다.
- **할인이 인원별로 여러 종류**(군위주민 1명 50%, 보훈 1명 30%, 사전예약자 17명 5% 등)면 같은 품명을 할인마다 한 줄씩 나눕니다.
  - 수량 많은 줄부터, 수량이 같으면 할인율 작은 줄부터
  - 품명 칸은 하나로 합쳐서 출력 (PDF · 엑셀 모두), 비고에 할인 종류
- **학생**: 예약인원에 학생이 있으면(`24명(어른 : 10명,학생 : 14명)`) 관람을 성인 줄과 학생 줄로 나눕니다. 학생 가격은 평일 45,000원 · 주말/공휴일 62,000원. 「성인 10명 10%」 「학생 14명 10%」처럼 적힌 할인은 맞는 줄에만 적용합니다. 학생 품목은 성인 관람과 같은 시간대(09:00~18:00 / 13:00~18:00)의 것으로 골라집니다.
- **금액으로만 적힌 할인**(`* 기타할인 - 400,000`)은 미리 받은 할인으로 보고, 그 양식 맨 아래에 외부용 할인 줄과 같은 모양(품명 「할인」과 금액만)으로 「할인 −400,000」을 넣습니다.
- **할인 줄은 양식마다 무조건 맨 아래**(견적금액 바로 위)에 나옵니다.
- 합계가 예약 금액과 다르면 "예약 정보 확인"에 `견적 합계 / 예약 금액 (차이)`가 뜹니다.

### 내부용 + 외부용 (고객 요청 수정본)

기본 정보의 **용도 → 내부용 + 외부용**을 고르면 **외부용 품목 바꾸기**가 나오고, 미리보기가 내부용 · 외부용 나란히 보입니다. 기준은 제목 옆 **(i)** 버튼에서도 볼 수 있습니다.

- 관람은 바꿀 수 없습니다.
- 관람은 품목을 바꿀 수 없습니다(수량만 따로 정할 수 있음, 아래).
- 수량은 **양식 전체 금액 기준으로 할인이 가장 적게** 자동으로 정합니다. 고른 품목은 바꾸지 않습니다.
  - 단체(시간): 3개 안에서 먼저 맞추고, 안 되면 5개까지
  - 단체(개별): 방문 인원까지
  - 수량을 직접 고치면 그 줄은 고정(초록 테두리)되고 나머지가 다시 맞춰짐. 칸을 비우면 다시 자동
  - 5개로도 모자라면 「추천: ○○ n개를 더하면 …」으로 단체(개별) 품목을 추천 → **더하기**
- 단가는 품목 관리 정상가이고, 내부용보다 늘어난 금액은 양식마다 **「할인」 한 줄**로 맞춰 합계가 내부용과 같아집니다. 예약의 금액 할인(기타할인)이 있으면 이 할인 줄에 합쳐 한 줄로 나옵니다.
- 외부용 합계가 내부용보다 적으면 **출력**할 때 확인 팝업이 뜹니다(양식별 내부용 · 외부용 금액과 차이). **사유를 반드시 적어야** 「사유 남기고 출력」이 눌리고, 「돌아가서 고치기」를 누르면 출력하지 않습니다. 사유는 발급 내역에 함께 남아 목록 구분 칸에 「차액」 버튼으로 보이고(누르면 사유 창), 발급 내역 엑셀의 「외부용 금액 차이 사유」 칸에도 들어갑니다. 재발행 · 수정발행 때는 지난 사유가 미리 채워집니다.
- **외부용 수량(인원수)**: 관람 · 그대로 쓰는 품목 카드의 **외부용 수량** 칸에 숫자를 넣으면 외부용 문서에만 그 수량으로 나옵니다(내부용은 그대로, 칸이 초록 테두리). 늘어난 금액은 외부용 「할인」 줄이 커져서 맞춰지고, 줄면 할인이 작아집니다. 할인으로도 못 맞출 만큼 줄면(외부용 합계가 내부용보다 적음) 출력할 때 사유를 적어야 합니다. 칸을 비우면 내부용 수량으로 돌아갑니다. 발급 내역에도 함께 저장됩니다.
- **외부용 품목 순서**: 품목 바꾸기 아래 목록에서 ⋮⋮를 잡고 끌어 놓거나 ▲▼로 순서를 바꿉니다(양식별). 끄는 중 커서가 화면 위 · 아래 끝(또는 화면 밖)으로 가면 저절로 스크롤됩니다. 외부용 문서 · PDF · 엑셀에 그 순서대로 나오고 내부용 순서는 그대로이며, 할인 줄은 늘 맨 아래입니다. 순서는 발급 내역에도 함께 저장되어 재발행 · 수정발행 때 그대로 돌아옵니다.

## 3단계 · 출력 · 메일

**출력**을 누르면 파일이 저장되고, 발급 내역에 기록되고, 메일 문구 창이 뜹니다. 처음에 브라우저가 「여러 파일 다운로드 허용」을 물으면 허용합니다.

| 용도 | 저장되는 파일 |
|---|---|
| 내부용만 | `사유원_견적서_수신_발행일.pdf` + `.xlsx` |
| 내부용 + 외부용 | `…_내부용.pdf`, `…_외부용.pdf`, `.xlsx` (시트1 내부용 · 시트2 외부용) |

- PDF와 엑셀 모두 사유원 · 신라철강 양식이 들어갑니다(엑셀은 한 시트에 위아래로, 인쇄 시 양식마다 한 장).
- 엑셀 직인은 발신 회사명 끝에 겹쳐 찍힙니다(PDF와 같은 자리).
- **엑셀을 인쇄해도 PDF와 같게**: 엑셀 열 너비 · 행 높이 · 인쇄 여백(A4, 왼쪽 · 오른쪽 52px, 위 46px)을 PDF 문서의 실제 위치를 재서 그대로 맞춥니다. 글꼴 크기 · 굵은 바깥선 · 회색 머리줄 · 합계 줄 · 안내문구(쪽 맨 아래, 회색 윗선)까지 같고, 양식마다 A4 한 장(페이지 나누기)입니다. 엑셀에서 숫자 · 글자를 고친 뒤 그대로 인쇄하면 됩니다. 칸은 PDF 칸 경계에 맞춘 11열 격자를 합쳐 쓰므로 품명 · 금액 등은 합쳐진 칸입니다.
- 견적서 아래에는 견적금액(총 금액)만 나오고 공급가액 · 부가세 줄은 넣지 않습니다.
- 저장한 파일 이름은 출력 버튼 아래에 표시됩니다.

**메일 문구 창**

- 제목: `[사유원] <수신>님 <문서> 송부드립니다.`
- 본문: `안녕하세요, 사유원입니다.` / `<수신>님 <문서> 송부드립니다.` / `감사합니다.`
- 위쪽에서 **견적서 / 거래명세서 / 견적서+거래명세서**를 고르면 문구가 바뀌고, 칸 안에서 직접 고칠 수 있습니다. **제목 복사** · **본문 복사**로 메일에 붙여넣습니다.
- 창을 닫았으면 출력 칸에 생기는 **메일 문구 다시 보기**로 다시 엽니다(출력하기 전에는 보이지 않음).

## 발급 내역 · 재발행 · 수정발행 · 발급 취소

출력할 때마다 발급 내역에 한 줄씩 자동으로 남습니다(발급 일시 · 구분 · 문서 · 수신 · 이용일 · 합계 · 담당 · 그때 문서 내용 전체). 위쪽 **발급 내역**으로 봅니다. 내역은 공유 저장소에 저장되어 **모두가 같이** 봅니다.

| 구분 | 언제 |
|---|---|
| 신규 | 발급 내역의 재발행 · 수정발행을 거치지 않은 출력 (아래 자동 수정발행에 해당하지 않을 때) |
| 재발행 | 발급 내역에서 **재발행**을 눌러 그때 내용 그대로 다시 만든 것 (거래명세서 발행일은 규칙대로 오늘) |
| 수정발행 | 발급 내역에서 **수정발행**을 눌러 불러와 고친 뒤 출력한 것. 화면 위에 「수정발행 중 · 원본 …」이 뜨고, 내역에 원본 일시와 연결되어 남음. 그냥 새 문서로 내려면 **수정발행 취소** |
| 수정발행(자동) | 발급 내역을 거치지 않고 출력했어도 **수신 · 이용일 · 문서 종류(견적서/거래명세서)가 같은 발급**이 있으면 같은 문서로 보고, 가장 최근 그 발급(발급 취소하지 않은 것 우선)의 수정발행으로 남음. 합계가 달라도 같은 문서. 예전에 「신규」로 들어간 같은 문서 발급도 화면 · 엑셀에서는 이 규칙으로 수정발행으로 정리해 보여 줌(저장된 내역은 그대로) |

- **한 줄 = 한 문서 · 버전(판) 고르기**: 같은 문서를 여러 번 발급했으면 한 줄로 묶이고, **발급 일시** 칸이 목록 상자로 바뀝니다(「2026.11.12 15:16 · 3판」, 아래에 「버전 3개 · 지금 3판 (최신)」). 처음엔 최신 판이 보이고, 다른 판을 고르면 그 줄의 구분 · 합계 · 담당과 **재발행 · 수정발행 · 발급 취소** 버튼이 모두 그 판 기준으로 바뀝니다. 발급할 때마다 그때 문서 내용 전체가 따로 저장되므로 어느 판이든 그대로 다시 낼 수 있습니다.
- 위쪽 개수는 「문서 15건 (발급 27번)」처럼 문서 수와 실제 발급 횟수를 함께 보여 줍니다. 검색은 어느 판이든 맞으면 그 문서를 보여 줍니다.
- **발급 취소**: 사유를 적고 취소합니다. 구분 칸의 「발급 취소」 버튼을 누르면 취소 일시와 사유가 창으로 보입니다. 내역은 지워지지 않고 「발급 취소」 표시와 취소 일시 · 사유가 남습니다. **취소 철회**로 되돌릴 수 있습니다.
- **검색**: 수신 · 담당 · 문서로 찾습니다.
- 창에는 **최근 500건**까지 보이고, 창 높이는 최대 720px(화면이 작으면 화면 높이 − 32px)입니다. 넘치면 표 안에서 스크롤되고 머리줄은 고정됩니다.
- **엑셀로 받기**: 저장된 내역 **전체**(500건이 넘어도 모두)를 `사유원_발급내역_날짜.xlsx` 한 시트로 받습니다. 칸: 문서 번호 · 판(예: 2 / 3) · 발급 일시 · 구분 · 원본 발급 일시 · 문서 · 용도 · 수신 · 이용일 · 발행일 · 합계 · 담당 · 상태 · 취소 일시 · 취소 사유 · 외부용 금액 차이 사유 · 품목 · 파일. 머리줄 고정과 필터가 걸려 있고, 발급 취소한 줄은 회색 취소선입니다.
- 인터넷이 끊겨 공유 저장소에 못 올린 내역은 브라우저에 보관했다가 다음에 자동으로 올립니다.

## 품목 관리

위쪽 **품목 관리**에서 예약 시스템 상품명과 견적서 품명 · 구분 · 발급처 · 정상가 · 과세 · 비과세 · 할인 대상을 봅니다. 예약 상품명이 목록과 같으면 자동 채우기에서 그 품목으로 들어갑니다. 목록은 **공유 목록**이라 모두가 같은 목록을 씁니다.

- 칸을 고치면 **2초 뒤 자동으로 저장**되어 공유 목록에 반영됩니다(위쪽 **저장**을 누르면 바로 저장). 상태 문구에 곧 저장 · 저장 중 · 저장 완료 · 연결 끊김이 보이고, 연결이 안 되면 15초마다 다시 저장합니다
- 닫을 때 남은 변경도 묻지 않고 저장합니다 (단체예약 도우미 안에서 연 품목 관리는 저장이 끝난 뒤 닫힘)
- **품목 검색**, **+ 품목 직접 추가**, **삭제**(여러 개는 체크 후 **선택 삭제**).
- **과세 · 비과세**: 정상가를 과세 · 비과세로 나눠 적는 품목은 이 두 칸에 금액을 적습니다(나누지 않는 품목은 비워 둠). 두 칸의 합이 정상가와 다르면 빨간 글씨로 「합 ○원 ≠ 정상가」가 뜹니다. 두 칸이 모두 있는 품목(새벽 해오름 산책)은 **문서에서 나뉩니다**: 비과세분(관람료)은 같은 날의 **평일 관람 · 주말 관람 줄 인원에 더해지고**(관람 줄과 할인율이 다르면 같은 「관람」 칸 아래 정가 줄로), 과세분은 원래 품명 그대로 한 줄입니다. 현장 결제면 관람은 ㈜사유원 양식(면세), 과세분은 신라철강㈜ 양식(VAT 포함), 인터넷 결제면 모두 ㈜사유원 양식(VAT 포함). 수량 · 할인율은 같고, 단가를 바꿨으면 같은 비율로 나눕니다. 외부용 할인 계산도 양식별로 나눠 맞춥니다. 입력 칸(내부용 문서 편집)에서는 한 줄 그대로입니다.
  - 사유원 새벽 해오름 산책(평일) 120,000원 = 과세 70,000 + 비과세 50,000
  - 사유원 새벽 해오름 산책(주말) 139,000원 = 과세 70,000 + 비과세 69,000
  - 입력 규칙(공유 목록에 입력됨): 관람 = 전액 비과세 · 관람+식사 = 비과세 평일 50,000 / 주말 69,000(관람가) + 나머지 과세 · 그 외(단체 프로그램 · 식사 · 몽몽마방 · 굿즈) = 전액 과세. 「썸머 스페셜」 4개는 아직 비어 있음
  - 관람+식사는 문서에서 이미 관람 줄 · 식사 줄로 나뉘므로 과세 · 비과세 칸으로 다시 나누지 않음
- **기본값으로**: 공유 목록 전체를 처음 목록으로 되돌립니다(자동 저장, **모두에게 바로 적용되니 주의**).
- 삭제한 기본 품목은 「기본값으로」를 누르면 돌아옵니다. 삭제한 품목을 쓰던 줄도 품목 칸이 빈칸으로 보이지 않습니다.

**구분** (이 순서로 보임)

| 구분 | 품목 예 | 발급 |
|---|---|---|
| 단체(시간) | 대관, 세미나, 해설사 · 임원 도슨트 | 기본 신라철강 (고를 수 있음) |
| 단체(개별) | 사운드워킹, 사유의 향, 요가프로그램, 음료쿠폰, 사유원 새벽 해오름 산책(평일) 120,000원 · 사유원 새벽 해오름 산책(주말) 139,000원 (관람료 포함, 할인 없음) | 기본 신라철강 |
| 관람 | 평일 · 주말/공휴일 관람, 학생 관람(평일 45,000원 · 주말/공휴일 62,000원, 성인처럼 09:00~18:00 · 13:00~18:00 두 품목씩 → 품명 「평일 관람(학생)」 「주말 관람(학생)」) | ㈜사유원 |
| 관람+식사 | 평일(관람, 사담 런치1부) 등 → 관람 · 식사 두 줄로 나뉨 | 관람 ㈜사유원 · 식사 신라철강 |
| 몽몽마방 메뉴 | 사유의 밥상(단체) → 사유의 밥상 38,000원, 몽몽마방 런치 → 비빔밥+녹두전+매실차 22,000원, 몽몽마방 단품 → 더덕비빔밥 17,000원 | 기본 신라철강 |
| 식사 | 사담 런치 · 디너 등 | 기본 신라철강 |
| 굿즈 | 판매 물품, 음료 · 와인 · 크로아상 | 기본 신라철강 |

- 몽몽마방 메뉴는 단체예약 도우미의 몽몽마방 식사 선택지로도 쓰입니다. 구분을 「몽몽마방 메뉴」로 하면 메뉴가 늘고, 품명 · 정상가를 바꾸면 도우미에도 반영됩니다.
- 기본 목록은 코드(`index.html`의 `CATALOG_RAW`)에 있고, 품목 관리에서 바꾼 내용은 공유 저장소에 저장됩니다.

## 한글 / 영어 입력

컴퓨터 입력기가 영문 상태여도 글자 칸(수신, 담당, 품명, 비고, 안내문구, 메일 문구, 품목 관리 등)에 치면 두벌식 한글로 들어갑니다. 예약 정보 붙여넣기 칸은 그대로 둡니다.

- 사이트를 열면 **항상 한글부터** 시작합니다.
- 영어가 필요하면 키보드 **한/영 키**, **Shift+Space**, 또는 위쪽 **한** 버튼(→ **A**). 다시 누르면 한글로 돌아옵니다.
- 한/영 키는 컴퓨터 입력기도 함께 바꾸지만, 글자는 항상 위쪽 한/A 표시대로 들어갑니다. 한/영 키 신호가 오지 않는 키보드에서는 다음 글자를 칠 때 한/A 표시가 바뀝니다.

## 관리자용: 공유 저장소(구글 시트 · Apps Script)

품목 목록과 발급 내역은 구글 시트 「견적서 품목 목록」에 저장되고, Apps Script 웹 앱(`index.html`의 `SHARED_URL`)을 통해 읽고 씁니다. 주소가 비어 있으면 각자 브라우저에만 저장됩니다.

| 시트 | 내용 |
|---|---|
| `catalog` | A1: 기본 목록에서 바뀐 부분(JSON), B1: 마지막 저장 시각. **직접 고치지 말 것** |
| `history` | 발급 내역 한 줄 = 한 번 발급. id · at · kind · parent · doc · client · useDate · issueDate · total · sender · use · files · snapshot · canceled · cancelNote |

- 웹 앱은 「실행 사용자: 나 / 액세스: 모든 사용자」로 배포되어 있습니다. 주소를 아는 사람은 목록과 내역을 읽고 고칠 수 있습니다(고객 개인정보는 수신 · 담당 이름 정도).
- 품목 변경은 「무엇을 바꿨는지」 단위로 보내 서버에서 합치므로, 여러 사람이 동시에 고쳐도 서로 지우지 않습니다.
- 시트와 Apps Script 프로젝트를 지우면 공유 목록 · 발급 내역이 사라집니다(휴지통에서 30일 안에 복구 가능).

**처음 설치**: `shared-catalog.gs` 맨 위 설명대로 script.google.com 새 프로젝트에 붙여넣기 → `setup` 실행(권한 승인, 시트 자동 생성) → 배포 › 새 배포 › 웹 앱 → 나온 주소를 `SHARED_URL`에.

**`shared-catalog.gs`를 바꿨을 때**: Apps Script 편집창에 새 코드를 통째로 붙여넣고 저장(Ctrl+S) → **배포 › 배포 관리 › 연필(편집) › 버전: 새 버전 › 배포**. 주소는 그대로입니다. 「새 버전」을 고르지 않으면 예전 코드가 계속 돌아갑니다. 배포가 반영됐는지는 웹 앱 주소를 열었을 때 `historyApi` 값으로 확인합니다(현재 3).

**코드 구성**

- `index.html`: 사이트 전체(화면 · 계산 · PDF · 엑셀). GitHub Pages로 배포되며 `main`에 push하면 1~2분 뒤 반영
- `shared-catalog.gs`: 공유 저장소 Apps Script
- 사용 라이브러리: ExcelJS, html2canvas, jsPDF, hangul-js (CDN)
