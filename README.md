# 사유원 견적서&거래명세서 발행기

예약 시스템의 상품 정보를 붙여넣으면 사유원 / 신라철강 견적서(또는 거래명세서)를 자동으로 채우고, PDF와 엑셀(.xlsx)로 내려받습니다.

사용: https://hyunbin5786.github.io/sayuwon-invoice-quotation/

## 사용 순서

1. **예약 정보 붙여넣기**에 예약 시스템의 상품 정보를 그대로 붙여넣고 **자동 채우기**
2. 기본 정보(수신 거래처명 등)와 품목을 확인 · 수정 — 오른쪽 미리보기가 바로 바뀝니다
3. **출력** (PDF와 엑셀이 함께 저장)

## 규칙

- 관람은 ㈜사유원(면세), 그 외 식음 · 프로그램 · 대관은 신라철강㈜(VAT 포함)
- 할인은 예약에 적힌 할인율을 할인 대상 품목(관람, 사담 다이닝)에만 적용
- 할인이 인원별로 여러 종류면(군위주민 1명 50%, 사전예약자 17명 5% 등) 같은 품명을 할인 종류마다 한 줄씩 나눠 수량 · 할인율 · 비고를 따로 넣음 (수량 많은 줄부터, 수량이 같으면 할인율 작은 줄부터, 품명 칸은 하나로 병합)
- 총 인원을 바꾸면 예약에서 들어온 품목 중 수량이 원래 인원과 같던 품목은 새 인원으로 바뀜 (할인별로 나뉜 품목은 수량이 가장 많은 줄에서 늘리고 줄임). 수량을 직접 고친 줄은 그대로
- 품목마다 수량이 다르면(입장 18명, 모과청 15개 등) 문서 수정하기에서 그 품목의 수량을 직접 고치면 됨
- 견적서 발행일은 이용일 이전. 이용일 이후 요청이면 발행일 = 이용일
- 거래명세서는 언제나 오늘 날짜로 발행 (발행일 칸은 잠김)

## 외부용 (고객 요청 수정본)

기본 정보의 **용도 → 외부용**을 고르면 "외부용 품목 바꾸기"가 나옵니다.

- **문서 수정하기**에서 고친 품목이 모든 문서의 기준입니다. 품목의 수량 · 단가 · 할인율 · 품명을 고치거나 행을 지우면 외부용도 바로 따라 바뀌고, 바꾼 품목 수량이 새 금액에 맞춰 다시 정해집니다.
- 관람은 바꿀 수 없습니다.
- 수량: 단체(시간) 품목은 3개 안에서 먼저 맞추고, 안 되면 5개까지 늘립니다. 단체(개별) 품목은 방문 인원까지.
- 수량을 직접 고치면 그 줄은 고정(초록 테두리)되고 나머지 줄이 할인이 가장 적게 다시 맞춰집니다. 칸을 비우면 다시 자동.
- 5개로도 모자라면 "추천: ○○ n개를 더하면 …" 으로 단체(개별) 품목을 추천하고, "더하기"를 누르면 들어갑니다.
- 품목마다 바꿀 품목(대관·세미나·도슨트·사운드워킹 등)을 고르면, 양식 전체 금액 기준으로 할인이 가장 적게 나오도록 수량을 자동으로 정합니다. 고른 품목은 그대로 둡니다. 한 품목을 여러 품목으로 바꿀 수 있고, 수량은 직접 고칠 수도 있습니다.
- 단가는 품목 관리 가격 그대로이고, 내부용보다 늘어난 금액은 양식마다 ‘할인’ 한 줄로 맞춰 합계가 내부용과 같아집니다. 모자라면 저장되지 않습니다.
- 출력 버튼은 하나입니다. 누르면 내부용 PDF · 외부용 PDF · 엑셀(시트1 내부용 · 시트2 외부용) 세 파일이 저장됩니다.

## 출력

"출력"을 누르면 사유원 · 신라철강 양식을 모두 담은 PDF와 엑셀이 함께 저장됩니다. 파일 이름은 `사유원_견적서_수신_발행일`이고, 외부용을 함께 만들 때만 PDF 이름 맨 뒤에 `_내부용` / `_외부용`이 붙습니다.

엑셀은 하나입니다. 시트 하나에 사유원 · 신라철강 양식이 위아래로 들어가고(인쇄 시 양식마다 한 장), 외부용을 함께 만들면 시트1 내부용 · 시트2 외부용입니다.

## 품목 관리

오른쪽 위 **품목 관리**에서 예약 시스템 상품 목록을 보고 고칠 수 있습니다. 예약 상품명이 목록과 같으면 자동 채우기에서 그 품목으로 들어갑니다.

구분은 단체(시간) → 단체(개별) → 관람 → 관람+식사 → 식사 → 굿즈 순으로 보입니다.

- 단체(시간): 대관, 세미나, 해설사·임원 도슨트
- 단체(개별): 사운드워킹, 사유의 향, 요가프로그램, 음료쿠폰, 사유의 밥상(단체)
- 굿즈: 판매 물품과 음료 · 와인 · 크로아상
- 관람: ㈜사유원
- 관람+식사: 관람(사유원)과 식사(신라철강) 두 줄로 나뉨. 식사 단가 = 정상가 − 관람료
- 단체 · 식사 · 굿즈: 발급처를 고를 수 있음 (기본 신라철강)

삭제한 품목은 바로 사라집니다. 기본 목록 품목은 "기본값으로"를 누르면 다시 돌아옵니다.

기본 목록은 코드(`index.html`의 `CATALOG_RAW`)에 있습니다.

### 공유 품목 목록

`index.html`의 `SHARED_URL`에 구글 시트 Apps Script 웹 앱 주소가 있으면, 품목 관리에서 바꾼 내용이 그 시트에 저장되어 모두가 같은 목록을 봅니다. 품목 관리를 열 때와 창으로 돌아올 때 최신 목록을 다시 불러옵니다. 주소가 비어 있으면 예전처럼 각자 브라우저에만 저장됩니다.

- 설치: `shared-catalog.gs` 맨 위 설명대로 script.google.com 새 프로젝트(또는 구글 시트의 Apps Script)에 붙여넣고, setup 실행 후 웹 앱으로 배포
- 예전에 자기 브라우저에서 고친 목록이 있으면 품목 관리에 **이 컴퓨터 목록으로 통일** 버튼이 나옵니다. 누르면 그 목록이 공유 목록이 됩니다 (공유 목록을 덮어씀)
- "기본값으로"는 공유 목록 전체를 되돌립니다

발신 담당자 이름은 각자 브라우저에 저장되어 다음에 목록에서 고를 수 있습니다.

## 한글 입력

컴퓨터 입력기가 영문 상태여도 글자 칸(수신, 담당, 품명, 비고, 안내문구, 품목 관리 등)에 치면 두벌식 한글로 바뀌어 들어갑니다. 예약 정보 붙여넣기 칸은 그대로 둡니다.

- 영어를 넣을 때는 위쪽 **한** 버튼을 눌러 **A**로 바꾸거나 Shift+Space. 다시 누르면 한글로 돌아옵니다 (각자 브라우저에 기억)
- 입력기가 이미 한글이면 손대지 않습니다

## 메일 문구

출력이 끝나면 메일 문구 창이 뜹니다 (출력 칸의 **메일 문구** 버튼으로도 열림). 제목과 본문을 고쳐 쓸 수 있고, "제목 복사" · "본문 복사"로 메일에 붙여넣습니다. 위쪽에서 견적서 / 거래명세서 / 견적서+거래명세서를 고르면 문구가 바뀝니다.

- 제목: `[사유원] <수신> <문서> 송부드립니다.`
- 본문: `안녕하세요, 사유원입니다.` / `<수신> <문서> 송부드립니다.` / `감사합니다.`
