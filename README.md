# 사유원 견적서 발행기

예약 시스템의 상품 정보를 붙여넣으면 사유원 / 신라철강 견적서(또는 거래명세서)를 자동으로 채우고, PDF와 엑셀(.xlsx)로 내려받습니다.

사용: https://hyunbin5786.github.io/sayuwon-invoice-quotation/

## 사용 순서

1. **예약 정보 붙여넣기**에 예약 시스템의 상품 정보를 그대로 붙여넣고 **자동 채우기**
2. 기본 정보(수신 거래처명 등)와 품목을 확인 · 수정 — 오른쪽 미리보기가 바로 바뀝니다
3. **출력** (PDF와 엑셀이 함께 저장)

## 규칙

- 관람은 ㈜사유원(면세), 그 외 식음 · 프로그램 · 대관은 신라철강㈜(VAT 포함)
- 할인은 예약에 적힌 할인율을 할인 대상 품목(관람, 사담 다이닝)에만 적용
- 발행일은 이용일 이전. 이용일 이후 요청이면 발행일 = 이용일

## 외부용 (고객 요청 수정본)

기본 정보의 **용도 → 외부용**을 고르면 "외부용 품목 바꾸기"가 나옵니다.

- 관람은 바꿀 수 없습니다.
- 품목마다 바꿀 품목(대관·세미나·도슨트·사운드워킹 등)을 고르면 수량을 자동으로 정합니다. 수량은 고칠 수 있습니다.
- 단가는 품목 관리 가격 그대로이고, 내부용보다 늘어난 금액은 양식마다 ‘할인’ 한 줄로 맞춰 합계가 내부용과 같아집니다. 모자라면 저장되지 않습니다.
- 출력 버튼이 "내부용 ○○ 출력"과 "외부용 ○○ 출력" 두 개로 나뉩니다.

## 출력

"출력"을 누르면 사유원 · 신라철강 양식을 모두 담은 PDF와 같은 내용의 엑셀이 함께 저장됩니다. 파일 이름은 `사유원_견적서_수신_발행일`이고, 외부용을 함께 만들 때만 맨 뒤에 `_내부용` / `_외부용`이 붙습니다.

## 품목 관리

오른쪽 위 **품목 관리**에서 예약 시스템 상품 목록을 보고 고칠 수 있습니다. 예약 상품명이 목록과 같으면 자동 채우기에서 그 품목으로 들어갑니다.

구분은 관람 → 관람+식사 → 식사 → 굿즈 순으로 보입니다.

- 관람: ㈜사유원
- 관람+식사: 관람(사유원)과 식사(신라철강) 두 줄로 나뉨. 식사 단가 = 정상가 − 관람료
- 식사 · 굿즈: 발급처를 고를 수 있음 (기본 신라철강)

삭제한 품목은 바로 사라집니다. 기본 목록 품목은 "기본값으로"를 누르면 다시 돌아옵니다.

기본 목록은 코드(`index.html`의 `CATALOG_RAW`)에 있고, 품목 관리에서 바꾼 내용은 각자 브라우저에만 저장됩니다.

발신 담당자 이름은 각자 브라우저에 저장되어 다음에 목록에서 고를 수 있습니다.
