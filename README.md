# 사유원 견적서 생성기

예약 정보를 붙여넣으면 사유원 / 신라철강 견적서를 자동으로 나눠 만들고, 엑셀(.xlsx)과 PDF로 내려받습니다.

사용: https://hyunbin5786.github.io/sayuwon-invoice-quotation/

## 직인

직인 이미지는 이 저장소에 없습니다. 각자 PC에 아래 이름으로 파일을 두고, 화면 오른쪽 위 **설정 · 단가표 → 직인 폴더 연결**에서 그 폴더를 한 번 연결하세요.

- `사유원_직인.png`
- `신라철강_직인.png`

연결 정보와 단가표는 각자 브라우저에만 저장됩니다.

## 프로필

처음 접속하면 담당자(이름 직함)와 이메일을 입력합니다. 견적서의 발신 담당자와 이메일로 들어가고, 견적서마다 확인 단계에서 수정할 수 있습니다.

프로필은 서버 없이 각자 브라우저에 저장됩니다. 다른 PC나 다른 브라우저에서는 다시 입력해야 합니다. 한 PC를 여러 명이 쓰면 프로필을 추가해서 전환할 수 있습니다.
